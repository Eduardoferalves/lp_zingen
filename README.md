# Zingen Landing Page

> Landing page simples do app **Zingen**, construída com HTML e CSS puros.

## Sobre

Esta página apresenta:

- Cabeçalho com navegação e botão de ação
- Seção hero com título, subtítulo e botões
- Cards de funcionalidades e planos
- Imagens de mockup e ícones
- Estilos responsivos e degradês

## Como usar

1. Abra `index.html` no navegador
2. Ou rode um servidor local e acesse `http://localhost:5500/index.html`

## Estrutura

| Caminho | Descrição |
|---|---|
| `index.html` | Arquivo principal |
| `styles/` | Pasta de estilos CSS |
| `assets/` | Imagens e ícones usados no layout |
